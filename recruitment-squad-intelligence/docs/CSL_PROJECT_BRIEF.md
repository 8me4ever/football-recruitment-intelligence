# 北京国安：引援与阵容规划项目

决策记录：2026-09-24；范围与年份定位修订：2026-09-27。

本项目唯一有效章程为 [`正式项目章程.md`](正式项目章程.md)。其中的 Gate 验收标准优先于本简报中的概括性状态。

## 产品目标

服务在中国足球行业求职的作品集。以北京国安为案例，在明确决策日期下识别阵容补强需求，从中超本土球员范围形成可解释的进一步考察名单。国籍与注册资格分开核验。旧Inter离队预测模块不是依赖项。

## 范围

- 数据定位：2026中超为主决策数据；2025为历史参照和跨赛季稳健性验证；2024待核实且暂不承诺纳入。
- 业务场景：以冻结决策日期 `2026-09-27` 评估国安当前阵容，并为下一阶段/新赛季规划提供证据。
- 采集参考池：全中超；深入分析对象：北京国安。
- 先做一个补强位置，由阵容诊断确定，不提前指定。
- 产出：需求报告、5–10人长名单、3人详细比较、视频证据与局限、可复现代码。
- 风格相似、表现质量、球队需求匹配分开呈现。
- 缺预算/合同条件时不宣称交易可行；无坐标时不宣称测得推进距离或完整战术风格。

## 数据结构约定

- `matches`：source、match_id、competition_id、season_id、日期、主客队ID、状态。
- `players`：来源ID与内部ID映射；姓名仅展示，不作为合并键。
- `lineups`：比赛/球队/球员、首发、替补、是否出场、原始位置。
- `player_match_stats`：逐场原始计数、成功/尝试、来源分钟、指标可用状态。
- `squad_membership`：俱乐部效力时间；与当场出场表分开。
- `provenance`：来源链接、采集时间、解析版本、质量标记、字段定义版本。

空白、未出场、未采集、来源不提供和明确0是不同状态。完整导入前不得默认补零。
