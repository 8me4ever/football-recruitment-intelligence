# Recruitment & Squad Planning Intelligence System

> 引援与阵容规划智能系统
> **状态：M1（干净数据层）✅ 已完成**

一个面向足球俱乐部决策支持的系统，连接**阵容风险识别**、**球员画像**、**替代者搜索**与**引援候选排序**。

---

## ⚠️ 本系统的诚实边界（先读这一节）

本项目在一个 MSc 项目的审计基础上重建。审计发现旧项目存在严重的方法论问题，因此**本节内容是本系统的设计前提，不是免责声明**。

### 我们**不做**的事

| 不做 | 原因 |
|---|---|
| 声称输出是"概率" | 未经过概率校准的分数不是概率。本系统输出**评分（score）**并明确标注 |
| 声称使用了"机器学习" | 除非真的训练了参数化模型。启发式规则会明确标注为启发式规则 |
| 编造缺失数据的代理 | 无转会费/薪资/伤病数据 → 就**不做**性价比与交易可行性分析 |
| 做联赛折算（跨联赛能力换算） | 数据仅有 Serie A，无跨国转会配对，无法估计折算系数 |
| 输出假精度（如 `Fit = 87.43%`） | 按样本量给出合理精度，并附不确定性 |
| 用随机数生成"实验结果" | 所有统计结论必须来自真实运行产物 |

### 我们**能做**的事（数据支持）

| 能做 | 数据依据 |
|---|---|
| 按位置的球员表现画像 | Serie A 全联赛约 600 名球员 × 101 个指标 |
| 引援候选池筛选 | 过滤后每赛季约 420–430 名可用球员 |
| 阵容风险识别（基于合同、年龄、出场、表现） | 合同 CSV + 年龄 + 分钟 + 百分位 |
| 球员风格相似度检索 | 行为统计分布（**无位置坐标数据，故为统计风格而非战术风格**） |
| 候选者质量与风格的**分离**排序 | 独立的两个维度 |

### 已知硬限制

1. **候选池仅限意甲** —— 无法推荐其他联赛的球员；
2. **无转会费 / 估值 / 薪资** —— 无法做预算与性价比分析；
3. **无伤病历史** —— 无法评估可用性风险；
4. **无位置坐标数据** —— 角色刻画基于行为统计，非触球热区；
5. **标签量极小**（旧项目仅 52 个"球员-赛季"观测）—— 故 M4 采用透明风险评分而非监督模型。

### M1 修复的旧项目缺陷（每项都有对应回归测试）

| # | 旧项目缺陷 | M1 处理 |
|---|---|---|
| 1 | `skiprows=2` 读入一行幽灵表头 | 改为 3，并断言第 3 行是标识行 |
| 2 | 无行数/列数断言，错位不被发现 | 断言每个表的数据行数与指标数 |
| 3 | 赛季中转会球员重复计入参考池（52 行） | 按球员聚合，计数求和、age 取最大 |
| 4 | 多位置信息被丢弃（118/143 人） | 保留 `positions_all`，主位置取 FBref 首个位置 |
| 5 | 低样本未过滤（最少 5 分钟） | 标记 `is_low_sample`，**不删除** |
| 6 | 合同 `-1` 当普通数值（且从未使用） | 拆分为 `is_loan` + `contract_years_left` |
| 7 | `except: return None` 静默吞异常 | 全部改为抛出 `DataLoadError` / `SchemaError` |
| 8 | 代码列名与数据列名不一致 | 统一规范化（`G+A`→`G_plus_A` 等） |
| 9 | 位置分组逻辑重复 4 次 | 唯一实现 + 单元测试 |
| 10 | 2024-25 HTML 从未解析 | 解析出 599 名球员（第 3 个赛季） |
