## 已观察到的字段与使用决定

| 字段组 | 实际观察 | 下一阶段处理 |
|---|---|---|
| 身份 | 球员链接ID、比赛ID、球队、日期 | 使用source+match_id+player_id作为唯一键 |
| 分钟与位置 | 显示分钟；G/D/M/F粗位置 | 保留来源口径；不能直接等同于细分角色 |
| 进攻 | Goals、Assists；详情中Total shots、Shots on target | 空白和0分开；不能把空白都当0 |
| 传球 | Accurate passes；Passing栏目有Touches、Key passes、Crosses、Long balls | 拆分成功/尝试；比例由总分子/总分母重新计算 |
| 防守 | Tackles；详情中Interceptions、Clearances、Recoveries | 单个数值的抢断成功数未知；不能自行补齐 |
| 对抗 | 总/地面/空中对抗及成功数 | 保留分子与分母 |
| 平台评分 | Sofascore Rating | 仅作参考；不是能力真值或学习标签 |
| 跑动 | 一场详情可见Distance covered、Top speed、Number of sprints | 定义、阈值和覆盖未核实，暂不入模 |
| xG/xA、推进传球 | 本次未确认 | 不纳入承诺交付字段；缺失不造代理 |
| 合同、费用、注册资格 | 比赛统计不能解决 | 后续单独来源核实；不从国籍推断资格 |

## 会影响实现的发现

1. **历史页面短暂错场。** 带 #id 的链接初次渲染可能先显示这两队另一场比赛，再切到指定日期。等待“页面加载”不够；需同时核验ID、日期和主客队，稳定后才保存。
2. **空白不等于0。** General表存在明确0及空白。当前解析器保留null和原始单元格，未判断空白是省略零还是缺失。12条样本中的助攻格均为空，不代表12人助攻均为0。
3. **分钟口径有疑点。** 玉昆—国安换人事件显示张玉宁86分钟上场，而General表显示18分钟；首发曹永竞显示90分钟。本次不解释为统一补时规则，也不自动改成4分钟。后续应比对球员详情、赛季汇总及另一来源。
4. **位置随比赛变化。** 同一个曹永竞ID817886，首轮为F，末轮为M；球员画像需要比赛位置分布，不能把最新位置回填所有历史。
5. **不能把赛后页面当赛前快照。** 2025历史页于2026采集，可能含后续更正或当前资料。历史评估要区分比赛发生日期、采集日期和真正当时可知的信息。
6. **General表不等于报名名单。** 未出场替补需要另存阵容表，不能因不在统计表中就断言未报名。

## 可复现产物

- `data/csl/pilot/general_table_samples.json`：12条选择性转录，保留空白及页面原文值。
- `data/csl/pilot/player_detail_observation.json`：第6场详情观察，单独存储，不伪装为General表数据。
- `scripts/validate_csl_pilot.py`：离线解析、重复键检查、比例校验、来源链接ID检查；不发起网络请求。
- `tests/test_csl_pilot.py`：针对空白/零、成功/尝试、舍入、分钟口径、重复键、错场链接及列顺序变化的回归检查。
- `data/csl/processed/pilot_normalized.json`：运行脚本后生成。

从项目根运行：
```powershell
python scripts/validate_csl_pilot.py
python -m unittest discover -s tests -p test_csl_pilot.py -v
```

运行环境：旧venv和系统py启动器本次均不能启动其配置的Python。改用Codex已提供的Python 3.12.14执行本原型，仅依赖标准库。这不等于旧M1环境已经修复或旧测试已经复现。

本次实际执行结果：6项回归测试通过；脚本生成12条标准化记录，覆盖5场比赛，12条均保留了至少一个空白字段。第6场详情仍单独存储。首次写出因沙箱拒绝创建目录而失败，获准重跑后写出成功。
